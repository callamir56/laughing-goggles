# esx_gangs

ESX Legacy + oxmysql + ox_inventory + ox_lib + ox_target

## نصب
1. پوشه `esx_gangs` را داخل `resources` بگذار.
2. فایل `sql.sql` را روی دیتابیس اجرا کن. (برای دیتابیس قدیمی هم مشکلی نیست — بخش‌های `CREATE TABLE IF NOT EXISTS` و `ALTER TABLE ... IF NOT EXISTS` خودشون ستون‌های جدید رو اضافه می‌کنن. خود سورس هم موقع استارت به صورت خودکار ستون‌های جدید را اضافه می‌کند.)
3. در `server.cfg`:
```
ensure oxmysql
ensure ox_lib
ensure ox_inventory
ensure ox_target
ensure es_extended
ensure esx_gangs
```

## دسترسی پنل
فقط گروه‌های زیر `/creategang` دارند:
- headadmin
- developer
- management
- gamemaster

## دستورات
| دستور | توضیح |
|---|---|
| `/creategang` | پنل ساخت و ادیت گنگ |
| `/setgang [id] [namegang] [rank]` | Set player gang. Remove: `/setgang id none 0` |
| `/addcargang [namegang]` | ماشین فعلی را به پارکینگ همان گنگ اضافه می‌کند. هر مدل فقط یک‌بار |

# سیستم تمدید / انقضای گنگ (جدید)

هر گنگ یک **دوره زمانی (روز تمدید)** دارد. وقتی این دوره تمام شود، گنگ **به صورت خودکار غیرفعال (Disabled)** می‌شود. با دکمه **تمدید (Renew)** یک دوره کامل جدید از همان لحظه شروع می‌شود و گنگ دوباره فعال می‌شود.

## ساخت گنگ
موقع ساخت گنگ در پنل (`/creategang`) سه تا فیلد هست:
- **Gang name** — اسم انگلیسی گنگ
- **Display label** — لیبل نمایشی
- **Renewal days** — روز تمدید (مثلاً ۳۰ یا ۱۰ یا هر عددی تا ۳۶۵)

> مقدار `0` یعنی **بدون انقضا (Unlimited)** و گنگ هیچ‌وقت خودکار غیرفعال نمی‌شود.

## دکمه‌های کنار Delete (وقتی گنگ ساخته شد و از لیست انتخاب شد)
کنار دکمه **Delete gang** چهار تا کنترل هست:

| کنترل | کار |
|---|---|
| **Renew (تمدید)** | یک دوره کامل جدید از همین لحظه شروع می‌شود (مثلاً دوباره ۳۰ روز کامل) + گنگ **فعال (Enabled)** می‌شود. حتی اگر هنوز منقضی نشده باشد هم می‌شود تمدید کرد (مثلاً روز ۲۹) و باز همان مقدار ست‌شده از اول حساب می‌شود. |
| **Enable (فعال)** | گنگ را دستی فعال می‌کند — فقط اگر دوره‌اش تمام نشده باشد. اگر منقضی شده باشد پیام می‌دهد که اول تمدید کن. |
| **Disable (غیرفعال)** | گنگ را دستی غیرفعال می‌کند (مثلاً برای تنبیه)، حتی اگر هنوز وقت داشته باشد. |
| **Change days (تغییر روزها)** | طول دوره گنگ را عوض می‌کند و **یک دوره جدید به همان اندازه از همین لحظه** شروع می‌شود (روزها = دوره بعدی تمدید هم هست). عدد `0` یعنی بدون انقضا. |

زیر اسم گنگ هم وضعیت و تاریخ دقیق نمایش داده می‌شود:
`30-day period · Expires 12 Oct 2026 (12 days left)`

در لیست گنگ‌ها هم گنگ‌های فعال یک **نقطه سبز** و گنگ‌های غیرفعال یک **نقطه قرمز** (و کم‌رنگ) دارند.

## قوانین غیرفعال شدن
- **خودکار:** به محض اینکه روزهای گنگ تمام شد (مثلاً ۳۰ روز گذشت و شد روز ۳۱)، سورس خودش متوجه می‌شود و گنگ را غیرفعال می‌کند. چک انقضا هر ۶۰ ثانیه یک‌بار انجام می‌شود (`Config.ExpiryCheckInterval`) و موقع استارت سرور/ریسورس هم بلافاصله اجرا می‌شود.
- **اعضا خبردار می‌شوند:** اعضای آنلاین آن گنگ پیام «Gang expired, now disabled» می‌گیرند.
- **تمدید:** با کلیک روی Renew، گنگ دوباره فعال می‌شود و شمارش از اول (مثلاً ۳۰ روز کامل) شروع می‌شود.

## گنگ غیرفعال چه می‌شود؟
وقتی گنگ غیرفعال باشد (دستی یا منقضی):
- استش / کمد لباس / پارکینگ / کرافت / باس منو **کار نمی‌کنند**
- لوکیشن‌ها و بلیپ گنگ روی مپ نمایش داده **نمی‌شوند**
- بلیپ لایو اعضای گنگ روی مپ پنهان می‌شود
- خود گنگ، اعضا، رنک‌ها، ماشین‌ها و پول گنگ **پاک نمی‌شوند** — فقط غیرفعال است و با تمدید/فعال‌سازی همه‌چیز برمی‌گردد

## نکته‌های مهم
- گنگ‌های قدیمی (قبل از این آپدیت) چون تاریخ انقضا ندارند **بدون انقضا** در نظر گرفته می‌شوند و هیچ‌وقت خودکار غیرفعال نمی‌شوند. برای فعال کردن سیستم روی آن‌ها، از دکمه **Change days** استفاده کنید.
- اگر ریسورس یا سرور ریستارت شود، وضعیت‌ها از دیتابیس خوانده می‌شوند و انقضاهای عقب‌افتاده بلافاصله اعمال می‌شوند.
- روزها باید عدد صحیح بین `0` تا `365` باشند.

## تنظیمات (config.lua)
| تنظیم | پیش‌فرض | توضیح |
|---|---|---|
| `Config.DefaultRenewDays` | `30` | روز تمدید پیش‌فرض هنگام ساخت گنگ |
| `Config.MaxRenewDays` | `365` | حداکثر روز قابل تنظیم |
| `Config.ExpiryCheckInterval` | `60000` | هر چند میلی‌ثانیه انقضای گنگ‌ها چک شود |

# سازگاری با HUD (رفع مشکل No Gang)

دیتای گنگ دقیقاً با **ساختار job خود ESX** ساخته و به همه جاهایی که HUD ها معمولاً می‌خونن هل داده می‌شه — یعنی هر HUD ای که شغل (job) شما رو درست نشون میده، گنگ رو هم می‌شناسه:

```lua
{
    name = 'ballas',          -- اسم داخلی
    label = 'Ballas',         -- لیبل نمایشی
    grade = 1,                -- عدد رنک
    grade_name = 'Boss',      -- اسم رنک
    grade_label = 'Boss',     -- لیبل رنک
    grade_salary = 0,
    isboss = true
}
```

این آبجکت اینجاها در دسترسه:

| کجا | چطوری بخونی |
|---|---|
| `ESX.PlayerData.gang` | مستقیم (مثل `ESX.PlayerData.job`) |
| Statebag کلاینت | `LocalPlayer.state.gang` (جدول) + `LocalPlayer.state.gang_grade` (عدد) + `LocalPlayer.state.gang_label` (متن) |
| Statebag سرور | `Player(src).state.gang` (مثل `state.job` خود ESX) |
| ایونت تغییر گنگ | `AddEventHandler('esx_gangs:playerGangChanged', function(gang) ... end)` — آبجکت بالا یا `nil` |
| Export سمت کلاینت | `exports.esx_gangs:GetMyGang()` |
| Export سمت سرور | `exports.esx_gangs:GetPlayerGang(src)` |

- دیتا موقع لود پلیر، ست/حذف گنگ، ارتقا/تنزل رنک، اخراج و هر sync فوراً آپدیت میشه + یه واچ‌داگ هر ۵ ثانیه اگه ریسورس دیگه‌ای دیتا رو پاک کرده باشه دوباره برمی‌گردونه.
- **نکته مهم:** قبلاً `LocalPlayer.state.gang` فقط یه رشته (اسم گنگ) بود؛ الان مثل `state.job` خود ESX **جدول** هست. اگه ریسورس دیگه‌ای داری که `LocalPlayer.state.gang == 'اسم'` مقایسه می‌کنه، باید `LocalPlayer.state.gang.name` رو بخونه.

# بقیه امکانات

## پنل
- ساخت گنگ با اسم انگلیسی + لیبل + روز تمدید
- ست کردن: پارکینگ، اسپاون ماشین، انبار، کمد لباس، باس منو، میز کرافت (لوکیشن فعلی ادمین)
- رنک تا حداکثر ۱۰ تا
- رسپی کرافت تا حداکثر ۱۰ تا
- لیست ماشین‌ها و حذف از پنل
- سیستم تمدید / انقضا (بالا)

## بلیپ لایو اعضا
- هر عضو گنگ هم‌تیمی‌هاش رو لایو روی مپ می‌بینه (بلیپ سیاه، اسم + رنک)
- بلیپ خود پلیر هم نمایش داده می‌شه؛ غیرفعال‌سازی: `Config.MemberBlip.showSelf = false`
- آپدیت هر ۱ ثانیه: `Config.GangBlipInterval` (میلی‌ثانیه)
- دیباگ: `/gangblips` — گنگ و تعداد بلیپ‌های فعال رو نشون می‌ده

## ایمپاند گنگ (۳ شرط)
1. ماشین بیرون باشه و ۵ ساعت (`Config.ImpoundIdle`) کسی سوارش نشه → ایمپاند گنگ
2. ماشین حذف بشه (`/cardel`) یا آب ببره → ایمپاند گنگ
3. سرور ریستارت بشه و ماشین بیرون باشه → ایمپاند گنگ (`Config.ImpoundOnRestart`)
- ماشین‌های داخل پارکینگ گنگ (stored) **هیچ‌وقت** ایمپاند نمیشن
- خروج از ایمپاند: NPC ایمپاند + $500 → ماشین برمی‌گرده به پارکینگ گنگ

## گنگ‌های اتحاد (Groups) و چت مذاکره
- ساخت گروه چندگنگی با چت تلگرامی
- چت مستقیم بین دو گنگ، ارسال لوکیشن، رابطه دشمن/دوست، بلاک گنگ
